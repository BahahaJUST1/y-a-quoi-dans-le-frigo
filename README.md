# Y'a quoi dans le frigo ?

![Logo du projet](./packages/frontend/public/git-logo.png)

---

### Prérequis

- Node version 22.14.0+
- Base de données MySql en local sur Wamp


### Installation

```bash
npm i
```


### Lancement

Depuis la racine du projet :

- Backend :
```bash
npm run backend
```

- Frontend :
```bash
npm run frontend
```
